# SQLiteXM Query Support

SQLiteXM fully supports two ways to work with data:

- **LINQ queries** for strongly typed, composable data access
- **Direct SQL** for statement-based control and advanced scenarios

Use LINQ when you want a queryable, C#-friendly approach. Use direct SQL when you want to write the SQL yourself or work at a lower level.
